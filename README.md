# Бот для Corebound

Запись игры, разметка и обучение. Работа идёт отсюда:
**github.com/krillxz2362/ultra-powder-toy** — там песочница, это отдельная задача.

## Запись касаний

Нужны Termux и Shizuku (настроен).

```
curl -sO https://raw.githubusercontent.com/krillxz2362/corebound-bot/main/запись_касаний.sh
rish -c "sh запись_касаний.sh"
```

Скрипт сам найдёт экран среди устройств ввода и начнёт писать касания
с временем и координатами. Останавливать Ctrl+C.

## Почему не по картинке

Сначала пробовали читать джойстик прямо из записи экрана. Пять
подходов: по яркости — ловится белый шарик из игры; по форме — ловится
само кольцо джойстика; по обесцвечиванию — ловятся края построек. Самый
удачный давал 90 %, но только на тёмном фоне: джойстик полупрозрачный и
на светлом перенимает цвет подложки.

Shizuku даёт права системной оболочки, и касания читаются точно. Заодно
видны прыжки и рывки, которых на картинке не видно вовсе.

## Разметка

`разметка.py` превращает запись экрана в данные для обучения: взгляд
бота 208x92 при 4 кадрах в секунду (меньше мегабайта на заход) и
журнал управления. Сама запись не хранится.
